# Triage Labels

| Papel | Valor no tracker | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Aguardando avaliação do mantenedor |
| needs-info | needs-info | Aguardando informações do autor |
| ready-for-agent | ready-for-agent | Especificado e pronto para um agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será implementado |

Quando uma skill mencionar um papel de triagem, use o valor
correspondente na linha `Status:` do ticket.
